# Example media

The MIT license applies to Filmworkbench's own code and original documentation, not model weights, third-party packages or generated media. Images and videos retain their applicable provider terms. H3 outputs must not be used for model training. The shared videos include a visible MiniMax H3 credit.

The eight recipe videos are selected S2 examples with their recorded assembly and audio policies. The original dialogue is German. They illustrate specific successful cases and visible limits, not a benchmark success rate. The reference stills are included to make the worked example inspectable and reproducible, subject to their provider terms.

“The Last Light” is a 78.75-second historical production example. It used GPT-generated cast/world images and a Krea 2 opening composition, six connected H3 clips, and a later clean-plate repair of an unwanted text/logo artifact. The English-subtitled version keeps the selected v3b audio unchanged. This example predates the later S1-audio policy; do not label its original soundtrack as S1 audio.

The eight smaller recipe examples use the documented S1-audio-under-S2 policy; K4 also contains a synthesized Qwen dialogue prelap. See each assembly file. Generated fictional characters are not real-person likeness references.

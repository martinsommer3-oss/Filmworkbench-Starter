# K2 — Reverse angle and return

[Video and workflow overview](../examples/K2/README.md)

[Watch the S2 example](https://github.com/martinsommer3-oss/Filmworkbench-Starter/releases/download/v0.1.0/Filmworkbench_K2_S2.mp4) · 28.54 seconds · 1952×1088 · 24 fps

## Recipe

Provide a matching opposite room view. Identify landmarks and explicitly swap character screen positions in the reverse shot, then return to the established wide.

## Known limits

A reverse can feel composited. A plausible view is not proof of a complete 3D room.

This is a selected development example with positive user feedback, not a measured success rate. The feedback file predates some bookkeeping updates; no new blanket approval of every variant is implied.

# K8 — A creature emerges from a lake

## Recipe

Start with an empty lake and provide a reference for the intended visible creature and scale. Reveal head, neck and back, then continue from the emerged state.

## Known limits

Water motion remains a visual judgment. The follow-up prompt retains some inherited start-description wording; this is a worked case, not a universal template.

This is a selected development example with positive user feedback, not a measured success rate. The feedback file predates some bookkeeping updates; no new blanket approval of every variant is implied.

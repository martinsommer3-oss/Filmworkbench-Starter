## Recipe

Use an actually empty opening plate, identity references and an unobstructed entry route. Specify when entry starts. The selected boat-house take also uses an end guide.

## Known limits

Do not generalize one successful entrance to all rooms. Rear/profile views limit face assessment; ambience can differ across the join.

This is a selected development example with positive user feedback, not a measured success rate. The feedback file predates some bookkeeping updates; no new blanket approval of every variant is implied.
